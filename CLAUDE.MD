## Repo Overview
A professional frontend engineer portfolio built using next.js, showcasing professional experience, skills and projects.

## Package Manager
Use npm. 

## Commands 
- `npm run build` - build the application for production 
- `npm run lint` - run ESLint
- `npm run format` - format code with Prettier
- `npm run test` - run tests

## Commit Conventions 
Use conventional commits:

`<type>[optional scope]: <description>`

## Workflow
Always invoke `/tdd` before making any code changes.
